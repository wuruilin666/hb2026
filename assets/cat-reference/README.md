## 已经对齐的要点

1. **不对称是这只猫的特征，不要为了好看改成对称。**
   视者**左侧**黑斑只到眼角外缘就停；视者**右侧**黑斑包住整只眼并往下延伸到脸颊。
2. 额头中间一道白色流星（从鼻梁一直通到头顶）。
3. 嘴部和下巴是白的。
4. 耳朵：外侧黑，内侧粉色开口约占耳朵的 2/5 —— 整体仍然读作"黑耳朵"。
5. 两颊都有淡粉腮红（`6.png` 两边都有）。
6. 身体：胸口、肚子正面、四条腿脚**全白**；黑色只出现在**腰侧外缘**，
   两块刻意不对称（右边一块更大、位置更高，左边一块更小、位置更低）。
7. 尾巴：黑色本体 + 中上段一道白环 + 黑色尾尖。
8. 红色项圈 + 银色铃铛。

> 注意身体斑块不要往下画到脚——之前一版画到了脚跟，看着像穿了黑靴子，
> 而参考照片里侧面看整片肚子和腿都是白的。

## 改色时的注意事项

- 黑斑用一个**整体形状** + `clipPath` 裁到脸型/尾型（`#catFaceClip` / `#catTailClip`），
  不要去描边缘——手描的边一定会和脸型对不齐。
- `#arm-left` / `#arm-right` / `#cat-head` / `#cat-tail` 这几个 id 被 `js/cat.js`
  和 `css/style.css` 的动画引用着，**改名会打断动画**。
- 对白框里的猫咪头像用 `<use href="#cat">` 复用本体，改了 `#cat` 头像会自动跟着变。
